# Internal publishing assets (private)

Store publishing workflow files (service-account script, localized
listings, release notes, store graphics) and the TODO handoff are
 intentionally **not** part of this public repository.

They live in the maintainer's local private archive, gitignored via
`.gitignore` (`TODO.md`, `scripts/`, `docs/store/`,
`docs/screenshots/store/`), and are never pushed.

Public repo = app code + portfolio site + top-level screenshots only.
